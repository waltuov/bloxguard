# BG003: runtime code execution

Default severity: high. Default confidence: high for a direct call.

## What it detects

BG003 reports `loadstring` use and patterns that construct source text before running it.

```luau
local FAKE_SOURCE = "return 1"
local compile = loadstring
compile(FAKE_SOURCE)
```

## Why it matters

Runtime compilation hides behavior from a static file review. Source may also arrive after the scan.

## False positives

Old admin systems and debugging tools may compile user supplied snippets. This remains risky even when intended.

## Suppression

Add a narrow suppression for `BG003`. Match the exact script path or fingerprint and explain why runtime compilation is required.

```toml
[[suppressions]]
rule = "BG003"
path = "/FAKE_Debug/Console"
reason = "FAKE local debug console is removed from production builds"
```
