# BG004: environment tampering

Default severity: high. Default confidence: high for direct calls. A global called by a computed name is medium severity and medium confidence. Reading a name that is not a Luau or Roblox global, and the output capture of a test that swaps `print` or `warn`, are low severity.

## What it detects

BG004 reports access to or changes of a function environment. This includes `getfenv`, `setfenv`, resolved aliases, and `setmetatable` on `_G` or `shared`, which changes what every global lookup returns.

Test runners such as TestEZ put their functions into the environment of each spec, and specs read them with `local it = getfenv().it`. A `getfenv()` or `getfenv(<number>)` call whose result is only read once, directly, at a constant name that is not a builtin, is reported low with the message `script reads a name that is not a Luau or Roblox global from its environment` and the name in the evidence, such as `[name: it]`. The forms are `getfenv().name` and `getfenv()["name"]`, also through an alias such as `local env = getfenv`.

Tests that check what code prints, such as the specs that Wally packages like luau-polyfill ship, capture `print` and `warn` in the environment of the function under test:

```luau
local function FAKE_capturePrint(...)
	table.insert(FAKE_printed, table.concat({ ... }, " "))
end

local function FAKE_withPrint(fn, ...)
	local saved = getfenv(fn).print
	getfenv(fn).print = FAKE_capturePrint
	fn(...)
	getfenv(fn).print = saved
end
```

Each of the three calls is reported low, with the key in the evidence, such as `[name: print]`. The environment is `getfenv()`, `getfenv(<number>)` or `getfenv(name)` with a local or a parameter as the name, and the key is `print` or `warn`, written `.print` or `["print"]`. The three shapes are:

- a save, `local saved = getfenv(fn).print`, when `saved` is put back at least once and every use of it is a restore,
- a restore, `getfenv(fn).print = saved`, which writes such a saved value back under the same key of the same environment, as the whole of a single assignment; a local that names the environment must never be assigned again,
- a replacement, `getfenv(fn).print = FAKE_capturePrint`, as the whole of a single assignment, where the value is a closed `local function` of the script that is never assigned again.

A closed function calls only `select`, `tostring`, `tonumber`, `type`, `typeof`, `table.insert`, `table.concat`, `table.pack`, `table.unpack`, `table.create`, `table.clear`, `table.remove`, `table.clone`, `string.byte`, `string.char`, `string.find`, `string.format`, `string.len`, `string.lower`, `string.match`, `string.rep`, `string.reverse`, `string.split`, `string.sub`, `string.upper`, and other closed `local function`s that are never assigned again, each by its plain name as `name(...)` or `table.name(...)`. The script must never assign these globals or write a field of `table` or `string`, and a local of the same name is not the library. A closed function, and every function defined in it, must not call a method or use a generic `for`. It may read and write a field or an index, `t.k` or `t[k]`, only of a plain table, and take `#` only of a plain table, a table constructor or a value that is never a table. A plain table is a local made by a table constructor, `table.pack` or `table.create`, never assigned again, that the whole script only indexes, measures with `#`, iterates as `for ... in t`, or passes first to `table.insert`, `table.concat`, `table.clear`, `table.remove`, `table.unpack` or `table.clone`. Any other use, such as `setmetatable(t, mt)`, a method call, an alias or passing it on, could give it a metatable. An operator other than `and`, `or` and `not` is allowed only on values that are never a table: literals, `#`, a numeric `for` counter that is never assigned, `select("#", ...)`, interpolated strings, the results of `tostring`, `tonumber`, `type`, `typeof`, `table.concat` and the string functions above except `string.split`, and arithmetic of those. Each of the excluded forms can run a function that is chosen elsewhere, also one assigned after the capture is defined, such as a callback, an iterator or a metamethod. None of the listed functions calls a function it is given, and the table ones read and write raw. `tostring`, `string.format` and interpolated strings run the `__tostring` metamethod of the values they format, and the formatted value can be one the capture stored or received from a helper, not only one passed to `print`. That metamethod is not followed (see [limits](../limits.md#values-the-scanner-cannot-follow)).

Everything else stays high:

- any other write to the environment, such as `getfenv().x = v`, `getfenv()["x"] = v`, `getfenv(1).x += 1`, or `rawset(getfenv(), "x", v)`, and a write of `print` or `warn` with any other value, such as `require`, `loadstring`, `print`, a global, a field, an inline `function`, a cast, or a local function that is not closed because it calls an upvalue, a global, a field, a method, `pcall` or a function assigned later,
- `setfenv` in any form,
- a computed key such as `getfenv()[name]`, a backtick string, or a number key,
- the environment table stored, passed or returned, such as `local env = getfenv()`, `f(getfenv())`, `return getfenv()`, or `getfenv():m()`, which passes it as `self`,
- `getfenv` with another argument, such as `getfenv(fn)` followed by any key but `print` and `warn`, `getfenv(f())`, or through a wrapper such as `pcall(getfenv)`,
- a constant read of a builtin, such as `getfenv().require`, `.loadstring`, `.game`, `.getfenv`, `.setfenv`, `.rawset`, `.setmetatable`, `.script`, `.shared` or `._G`, and a read of `print` or `warn` that is not a save: called, passed to a function, returned, stored, or saved in a local that is never put back or is also used another way.

The builtin list is `ENVIRONMENT_BUILTINS` in `crates/bloxguard-core/src/analysis.rs`, the one place that defines it. It holds the Luau globals and libraries from Luau's builtin definitions (`assert` to `xpcall`, `bit32`, `buffer`, `coroutine`, `debug`, `math`, `os`, `string`, `table`, `utf8`, `vector` and the others), the Roblox globals from luau-lsp's Roblox definitions (`game`, `workspace`, `script`, `plugin`, `shared`, `task`, `Enum`, `Instance`, `settings`, `UserSettings`, `wait`, `delay`, `spawn`, `tick`, `time`, `warn` and the others), the Roblox data type constructors (`CFrame`, `Vector3`, `Color3`, `TweenInfo`, `RaycastParams`, `SharedTable` and the others), and legacy aliases such as `Game`, `Workspace`, `ypcall` and `printidentity`.

It also reports a global function called by a name the scanner cannot fold: a call through `_G[name]`, `shared[name]`, `getfenv()[name]`, or `rawget(_G, name)`, a function taken from a loop over `pairs(_G)` or `next, _G`, or a proxy table whose `__index` function returns `_G[key]`. Names built with `string.gsub`, `match`, `find`, `split`, `utf8.char`, and similar calls with constant arguments are folded first, so a resolved name is checked as a normal call.

The other rules follow what the script stores through its environment: `getfenv().x = v` and `rawset(getfenv(), "x", v)` assign the global `x`, so a later `require(x)` sees `v`. A write under a name the scanner cannot read leaves every global of the script unresolved.

```luau
local readEnvironment = getfenv
local FAKE_ENV = readEnvironment()
```

## Why it matters

Environment access can hide dependencies, replace trusted functions, or reach a loader through an indirect name.

## False positives

Older libraries may inspect environments for compatibility. Review whether the code can use explicit dependencies instead. A plugin system or command router that calls global functions by name also matches the computed name check.

Code that legitimately builds and runs code, such as a Roblox emulator that loads module sources with `loadstring` and `setfenv`, a test runner that sets the environment of each spec, or a Studio plugin that runs code the user typed, gets BG003 and BG004 at high severity. That is expected for such a tool. Review it once and suppress both rules by path for the files that do it.
