# BG007: runtime asset loading

Default severity: high. Default confidence: high for a resolved service call.

## What it detects

BG007 reports runtime asset loading through APIs such as `InsertService:LoadAsset` and `game:GetObjects`.

```luau
local FAKE_ID = 999000000000007
game:GetService("InsertService"):LoadAsset(FAKE_ID)
```

## Why it matters

The loaded object is outside the offline scan. It may contain scripts or properties that were not reviewed.

## False positives

Some authorized build tools and asset browsers load known assets. Confirm ownership, validation, and whether the call can run in production.

## Suppression

Add a suppression for `BG007` at the loader script. Explain which assets are allowed and how their contents are reviewed.

```toml
[[suppressions]]
rule = "BG007"
path = "/FAKE_Tool/AssetPreview"
reason = "FAKE internal preview tool runs only in Studio"
```
