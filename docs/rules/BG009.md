# BG009: delayed or conditional activation

Default severity: medium. Default confidence: medium.

## What it detects

BG009 reports a risky action that a gate controls. The risky action is a finding of another rule in the same script: a module load by ID at high severity (BG001), an instance sourced module load (BG002), runtime code (BG003), environment access (BG004), a runtime asset load (BG007), HTTP exfiltration at high severity (BG008), or an inserted purchase prompt or teleport (BG010). An unresolved low `require` alone is not a risky action.

A gate controls the action when the action runs:

- in a branch of an `if`, `elseif`, or `else` whose condition checks Studio (`IsStudio`), the creator, place, game or server (`CreatorId`, `CreatorType`, `PlaceId`, `GameId`, `JobId`, `PrivateServerId`, `PrivateServerOwnerId`), the player count (`GetPlayers`), or the clock (`DateTime.now`, `os.time`, `os.date`, `os.clock`, `tick`, `time()`),
- after an early `return` or `break` behind such a check, after `if check then error(...) end`, or after `assert(check)`,
- in an operand after such a check in `and` or `or`, such as `not RS:IsStudio() and require(id)`, or in a branch of an if-expression on such a check,
- inside a `while` loop on such a check, or after it, or after a `repeat` loop that waits until one,
- after a wait of at least 60 seconds in the same block, or inside a function passed to `task.delay` or `delay` with such a delay,
- inside a function of the script that is called under such a gate, such as a wrapper without arguments called only in `if game.PlaceId == id then`, or a function chosen by a gated expression, such as `local f = if game.CreatorId == id then require else print`.

A condition counts through its text, through a variable assigned from a check (`local studio = rs:IsStudio()`), through a local function that returns or calls one, and through `IsStudio` reached by an alias or a computed method name. A member under a bracket key built from strings counts too, such as `game["PlaceId"]`, ``game[`PlaceId`]`` or `game["Place" .. "Id"]`, also through a local that holds the key. A key the scanner cannot fold, such as `game[FAKE_name]`, does not count. Delays fold arithmetic such as `3600 * 24 * 7` and use the lower bound of `math.random(a, b)` and `Random:NextInteger(a, b)`. A check elsewhere in the script that does not control the action is not reported.

```luau
if not game:GetService("RunService"):IsStudio() then
    task.wait(9999)
    require(999000000000001)
end
```

## Why it matters

Conditional activation can hide behavior during testing and code review. Long delays can avoid short play sessions.

## False positives

Studio debug code, environment configuration, scheduled events, and normal startup delays can match when they guard one of the risky actions above. Review what the condition protects.

## Suppression

Add a suppression for `BG009` at the exact script or use its fingerprint. Explain the legitimate environment difference.

```toml
[[suppressions]]
rule = "BG009"
path = "/FAKE_Debug/StudioOverlay"
reason = "FAKE overlay is intentionally available only in Studio"
```
