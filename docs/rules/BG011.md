# BG011: external package link

Default severity: medium. Default confidence: medium. A package ID proves that the content is linked to a package asset. The scanner cannot tell who owns that asset, so it does not claim high confidence.

## What it detects

BG011 reports package links that can pull updates from content outside the scanned file or source tree. It reads a `PackageLink` in `.rbxl`, `.rbxlx`, `.rbxm`, and `.rbxmx` files, in source trees, and in bundles. It checks every spelling of the package reference: `PackageId`, `PackageIdSerialize`, `PackageContent`, and `PackageContentSerialize`, plus older package fields. The Roblox decoders turn `PackageId` and `PackageIdSerialize` into `PackageContent` while loading a file, so the check reads all of them. A script `LinkedSource` that points at an asset is also reported.

An empty reference, `rbxassetid://0`, and local `rbxasset://` paths are not reported.

## Why it matters

A linked package can change after the current review. The offline scan cannot inspect a future package version.

## False positives

Teams often use packages they own. Confirm the package owner, update policy, and whether automatic updates are enabled.

## Suppression

Add a suppression for `BG011` at the package root. State who controls the package and how updates are reviewed.

```toml
[[suppressions]]
rule = "BG011"
path = "/FAKE_SharedPackage"
reason = "FAKE team package updates require code review"
```
