# BG012: command execution instructions

Default severity: high. Matches in comments have medium confidence. Every other match has high confidence.

## What it detects

BG012 reports text that tells a developer to paste or run code in the Studio command bar, the developer console, or another privileged context. It checks:

- source string literals and source comments,
- `StringValue` values,
- shown text: `Text` and every other `*Text` property such as `PlaceholderText` or `ActionText`, plus `ToolTip` and dialog lines,
- instance names,
- string attributes on any instance.

The text must name a command surface such as "command bar", "cmd bar", "developer console", or "dev console". It must also give a direct instruction such as "paste this", or combine a verb such as "run" or "type" with Luau like `require(` or `game:GetService`. Before matching, the scanner removes invisible characters and combining marks, reads fullwidth and look alike letters as ASCII, and treats punctuation as spaces. "Command-Bar" and "cmdbar" therefore match too.

```luau
local FAKE_MESSAGE = "Paste the FAKE setup command into the command bar"
```

## Why it matters

Social engineering can ask a developer to bypass normal review and run code with broad Studio access. A model can carry these instructions in a label, a tool tip, an attribute, or an object name instead of a script.

## False positives

Tutorials and internal documentation may explain command bar workflows. Comments can also contain warnings or examples. Check whether the text asks someone to run code and whether it contains executable content.

## Suppression

Add a suppression for `BG012` at the reviewed tutorial object. Explain where the instructions appear and why they are safe.

```toml
[[suppressions]]
rule = "BG012"
path = "/FAKE_Tutorial/CommandBarLesson"
reason = "FAKE internal tutorial contains no executable command"
```
